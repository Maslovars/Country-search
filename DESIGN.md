# DESIGN.md — архитектура Country Search

## 1. Отмена устаревших запросов

Обработчик `input` в `src/ui/app.ts` вызывает `CountrySearchController.handleInput` при каждом изменении значения. Контроллер сразу:

1. увеличивает версию текущего запроса;
2. вызывает `abort()` у предыдущего `AbortController`, если запрос уже начался;
3. отменяет ожидающий debounce-вызов;
4. для непустого значения планирует новый запрос.

Отмена выполняется именно в момент изменения ввода, а не внутри отложенного callback debounce. Поэтому ранее запущенный `fetch` не продолжает работать в течение следующих 350 мс.

При запуске запроса создаётся новый `AbortController`. Его сигнал объединяется с таймаутом:

```ts
const timeoutSignal = AbortSignal.timeout(timeoutMs);
const signal = AbortSignal.any([controller.signal, timeoutSignal]);
```

При вводе нового текста исходный controller abort-ится, и `fetch` получает `AbortError`. Если время ожидания истекло, объединённый сигнал отклоняет запрос с `TimeoutError`. В `classifySearchError` эти два случая различаются. `AbortError` не показывается пользователю, потому что это ожидаемая реакция на новый ввод или очистку поля. `TimeoutError` отображается как настоящая ошибка с кнопкой повтора.

Одной отмены недостаточно для защиты UI от произвольного транспорта или тестовой заглушки, которая некорректно игнорирует сигнал. Поэтому контроллер также проверяет номер версии перед обновлением состояния. Это дополнительная защита от устаревшего результата, но она не заменяет `AbortController`: фактическая отмена всё равно выполняется и проверяется в тесте гонки.

HTTP 404 обрабатывается в `searchCountries`: countries.dev использует его для случая «совпадений нет», поэтому функция возвращает `[]`. Для других неуспешных HTTP-ответов выбрасывается `HttpError` со статусом. Ошибки сети также доходят до контроллера и отображаются пользователю.

## 2. Задержка debounce

Используется задержка **350 мс** (`SEARCH_DEBOUNCE_MS` в `src/config.ts`). Она позволяет объединить быстрый набор слова в один запрос и при этом не создаёт слишком заметной паузы после остановки ввода.

Без debounce запрос отправлялся бы после каждого символа. Это увеличило бы количество сетевых обращений и вероятность появления ненужных ответов. Слишком большая задержка (например, 1000–1500 мс) экономила бы запросы, но делала поиск ощутимо медленным. 350 мс — компромисс для короткого поиска по названию.

Важно: debounce управляет только запуском следующего запроса. Предыдущий активный запрос отменяется сразу при событии `input`.

## 3. Сложность алгоритмов

### `mapCountryResponse(raw)`

Преобразование проходит по фиксированному количеству полей страны. Для массивов `languages`, `currencies` и `borders` выполняется линейный проход. Если `L`, `C` и `B` — размеры этих массивов, сложность по времени равна **O(L + C + B)**, а дополнительная память — **O(L + C + B)** для нового объекта и нормализованных массивов. По отношению ко всему объекту ответа это линейная сложность **O(n)**.

### `debounce(fn, delay)`

Каждый вызов сбрасывает один таймер и сохраняет последние аргументы: **O(1)** времени и **O(1)** дополнительной памяти, не считая самого callback.

### Поиск

Сложность сетевого поиска определяется API и размером ответа. Преобразование массива из `m` стран занимает **O(m × k)**, где `k` — суммарное количество вложенных языков, валют и границ одной страны. В проекте бонусный in-memory cache и дедупликация не реализованы.

## 4. Принципы чистого кода

- **Single Responsibility:** `searchCountries` отвечает за HTTP-запрос и HTTP-статусы; `mapCountryResponse` — только за преобразование данных; `classifySearchError` — за классификацию ошибок; UI отвечает за DOM.
- **Чистая функция:** `mapCountryResponse` не обращается к сети, DOM или глобальному состоянию и не изменяет исходный объект.
- **Явные зависимости:** `CountrySearchController` принимает функцию поиска и callback изменения состояния через параметры конструктора, что упрощает тестирование.
- **Небольшие функции:** преобразование языков, валют, флага и капитализации вынесено в отдельные функции mapper-модуля.
- **Изоляция UI-детали:** `src/ui/countryFlag.ts` отвечает только за отображение флага. Он использует URL SVG/PNG, а при ошибке загрузки или отсутствии URL показывает Unicode-эмодзи. `src/ui/__tests__/countryFlag.test.ts` проверяет оба fallback-сценария.
- **Константы вместо магических значений:** задержка debounce, таймаут и базовый URL API находятся в `src/config.ts`.
- **Защита от небезопасного HTML:** UI использует `createElement`, `append`, `replaceChildren` и `textContent`; `innerHTML` и `insertAdjacentHTML` не используются.
- **Типизация состояний:** `SearchState` — discriminated union, поэтому состояния `idle`, `loading`, `success`, `empty` и `error` имеют явные поля.
